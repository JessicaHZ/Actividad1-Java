# Actividad 1 - Sistema de Votación en Java

## Descripción del Proyecto

Este proyecto consiste en el desarrollo de una aplicación de consola en Java que simula un sistema básico de votación.

El programa permite ingresar votos de manera consecutiva indicando el número del candidato (1, 2 o 3). El proceso de votación finaliza cuando el usuario ingresa el valor 0.

Una vez terminada la captura de votos, el sistema calcula y muestra el porcentaje de votos obtenidos por cada candidato con respecto al total de votos registrados.

## Funcionamiento

1. El sistema solicita el número del candidato.
2. Se registran los votos hasta que se ingresa 0.
3. Se calcula el total de votos.
4. Se muestran los porcentajes obtenidos por cada candidato.
